# docs/

This folder is reserved for your own project artifacts — it isn't required
for the site to run.

- **`prototype.pdf`** — drop in a design prototype or storyboard here if you
  have one (e.g. exported from Figma).
- **`screenshots/`** — drop in screenshots of the finished site here, useful
  for a repo's README preview or for sharing progress with others.

Neither file is referenced by the site itself, so the project runs fine
without them.
